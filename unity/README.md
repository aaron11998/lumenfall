# LUMENFALL Unity prototype (AGE-140)

Unity 2022.3 LTS (URP) leg of the LUMENFALL build matrix. See `../BUILD_MATRIX.md`
for the contract. CI entry point: `Assets/Editor/AABuild.cs` (batchmode
`-executeMethod Lumenfall.EditorTools.AABuild.Build`).

Layout:
- `Assets/Scenes/Bootstrap.unity` — minimal smoke scene (generated by editor on first open; CI-safe)
- `Assets/Editor/AABuild.cs` — batch build + gate script
- `Assets/Tests/EditMode/` — EditMode smoke tests (Unity Test Runner, `-runTests -testPlatform EditMode`)

Build invocation (what CI runs):

```bash
"$UNITY_BIN" -batchmode -nographics -quit \
  -projectPath "$PROJ/unity" \
  -executeMethod Lumenfall.EditorTools.AABuild.Build \
  -logFile -
```

Gate: exit 0 AND zero compiler errors (enforced in AABuild.cs via
`EditorUtility.scriptCompilationFailed` + `BuildPlayer` report).
